# Super Riso Lab

Riso, fotocopia y stencil para cualquier ilustración. Una sola página, sin servidor: todo se procesa en tu navegador (WebGL2).

- Abre `index.html` (o la URL publicada), arrastra una imagen y elige técnica y estilo.
- Exporta PNG/JPG/WebP a cualquier tamaño de hoja y resolución, tiradas en .zip, planchas riso y vídeo de reimpresión.

Requisitos: un navegador con WebGL2 (Chrome, Edge, Firefox, Safari 15+).

Créditos: motor y texturas propios (Dumaker). Lista de tintas riso: riso-colors (MIT, Matt DesLauriers).
